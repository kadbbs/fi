# fi

`fi` 是一个轻量级终端文本编辑器，提供多文件缓冲区、文件侧边栏、命令模式和内嵌 Shell。项目使用 C++17 编写，面向支持 POSIX PTY 的 Unix/Linux 终端。

## 功能

- 多文件编辑：启动时可同时打开多个文件，编辑内容和光标位置分别保存在各自的缓冲区中。
- 文件侧边栏：显示已打开文件、当前文件和未保存标记；终端宽度至少为 50 列时显示。
- 编辑操作：方向键、Home/End、Page Up/Page Down、Enter、Backspace 和 Delete。
- 撤销/重做：通过命令回退或恢复最近的编辑操作，每个文件分别保留最多 200 步。
- 终端缩放：窗口尺寸变化时自动重排编辑区、侧边栏和 Shell 面板，并同步调整 Shell PTY。
- 缓冲区管理：可创建空缓冲区、关闭当前缓冲区，并对未保存更改进行确认。
- 行号：默认开启，可通过命令切换。
- 内嵌 Shell：使用 PTY 启动交互式 Shell，支持常见 ANSI 颜色、清屏、光标移动和输出回看。
- 未保存保护：退出时检查所有已修改缓冲区，可选择保存后退出、放弃更改或取消。

## 构建

需要 CMake 3.16 或更高版本，以及支持 C++17 的 C++ 编译器。使用 `/usr/bin/g++` 构建：

```sh
cmake -S . -B build -DCMAKE_CXX_COMPILER=/usr/bin/g++
cmake --build build --parallel
```

## 运行

打开一个或多个文件：

```sh
./build/fi file.txt
./build/fi main.cpp README.md
```

也可以不带文件启动，再通过 `:open` 打开文件：

```sh
./build/fi
```

## 操作

按 `Esc` 进入命令模式，在底部输入以冒号开头的命令并按 Enter 执行。按 `Esc` 可取消命令输入并返回编辑。

| 命令 | 说明 |
| --- | --- |
| `:open <文件>`、`:e <文件>` | 打开文件；若文件已打开，则切换到对应缓冲区 |
| `:buffers` | 在状态栏列出已打开文件及未保存标记 |
| `:buffer <编号>`、`:b <编号>` | 切换到指定编号的文件 |
| `:bnext`、`:bn` | 切换到下一个文件 |
| `:bprev`、`:bp` | 切换到上一个文件 |
| `:new` | 创建并切换到一个新的空缓冲区 |
| `:bd` | 关闭当前缓冲区；有未保存更改时询问是否保存 |
| `:bd!` | 丢弃当前缓冲区的更改并关闭 |
| `:undo`、`:u` | 撤销最近一次编辑操作 |
| `:redo` | 重做最近一次撤销的编辑操作 |
| `:w [文件]` | 保存当前文件；可选指定另存为路径 |
| `:wq`、`:x` | 保存当前文件并退出；其他缓冲区如有未保存更改，会继续提示 |
| `:q` | 退出；有未保存更改时会提示是否保存所有已修改文件 |
| `:q!` | 不保存并退出 |
| `:find <文本>` | 从当前位置向后查找文本 |
| `:set number` | 开启行号 |
| `:noset number` | 关闭行号 |
| `:shell` | 打开内嵌 Shell 面板并切换焦点到 Shell |
| `:shell close` | 关闭内嵌 Shell |
| `:help` | 在状态栏显示常用命令 |

### 内嵌 Shell

- 在编辑器与 Shell 之间按 `F6` 切换焦点。
- Shell 获得焦点时，键盘输入和方向键会发送给 Shell。
- Shell 焦点下使用 `Page Up` / `Page Down` 查看历史输出；最多保留 2000 行。
- Shell 支持常见 ANSI SGR 颜色、清屏、光标定位和行/字符编辑控制。它不是完整的终端模拟器，依赖备用屏幕或其他高级终端特性的交互式 TUI 程序可能无法正常显示。

## 注意事项

- 侧边栏在窄终端（少于 50 列）中隐藏，以给编辑内容留出空间。
- `:bd` 的确认提示中，按 `y` 保存并关闭，按 `n` 丢弃并关闭，按 `Esc` 取消；关闭最后一个缓冲区后会自动创建空缓冲区。
- 撤销和重做按编辑操作记录；输入的每个字符及每次换行、删除分别作为一个操作。
- 每个缓冲区在保存时写入对应文件；新建空缓冲区可使用 `:w <文件>` 指定文件名。
- 退出时选择 `y` 会保存所有已修改且已有文件名的缓冲区；若某个缓冲区没有文件名，保存会失败并保持编辑器打开，可先为它指定文件名。
